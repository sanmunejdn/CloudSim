## 待人工点验（二期）

1. 启动 Debug（`bin/x64d`）或 Release（`bin/x64`），确认加载 `com.cloudsim.drawing`（需宿主 ≥ 1.34.0）
2. 进入工程图 → 选 B-rep → 切换第一/第三角、勾选轴测/剖视 → **生成**
3. 工具「选择/拖视图」拖动各视图；「线性尺寸」两点标注；「局部放大」拖框生成细节视图
4. 导出 SVG / DXF，用外部查看器确认线型与尺寸
5. 保存/再打开，确认视图与尺寸恢复
6. 与工艺流程、几何建模互斥切换；确认侧栏走 `enterAlternateSideUi`
