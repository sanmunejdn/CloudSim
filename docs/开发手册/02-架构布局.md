# 02 — 架构与目录布局

## 解决方案

| sln | 入口 | 工程表 |
|-----|------|--------|
| `CloudSim/CloudSim.sln` | `CloudSim.exe` | [CloudSim.sln.md](../solutions/CloudSim.sln.md) |
| `CloudSim/CloudSimWeb.sln` | `CloudSimWeb.exe` | [CloudSimWeb.sln.md](../solutions/CloudSimWeb.sln.md) |

两套 sln **互不引入**对方的 UI/Web 工程；共享 Contracts / Data / Robot / Geometry / Infra / 多数 SDK。桌面用 `CloudSimHost`，网页用 `CloudSimHostHeadless`（共享源，见 [Host 同步](../features/网页端/Host同步/README.md)）。

完整目录与工程对照：[DIRECTORY_LAYOUT.md](../DIRECTORY_LAYOUT.md)。  
架构图：[desktop](../features/架构/desktop.html) · [web](../features/架构/web.html)。

## 域划分

| 域 | 路径 | 职责 |
|----|------|------|
| App | `src/App/` | `CloudSim.exe` / `CloudSimWeb.exe`、Bootstrap 头 |
| Contracts | `src/Contracts/` | `CloudSimCore`、`KinematicCore` |
| Host | `src/Host/CloudSimHost` | 文档宿主、组合根；桌面编 OsgWidget |
| UI | `src/UI/` | Widget、RobotWidget、OsgWidgetCore、BackendVisual、AiWidget、PluginHost |
| Robot | `src/Robot/` | URDF、Scene、轨迹、运动学、路径规划 |
| Geometry | `src/Geometry/` | OCC/CGAL、碰撞、点云、VCG、InstantMeshes |
| Data | `src/Data/` | 后端对象、工程持久化 |
| Plugins | `src/Plugins/` | 工作区模式 + 侧栏 + SDK |
| Web | `src/Web/` | CloudSimWebGateway |
| Infra | `src/Infra/` | RunLogger |

## 依赖方向

日常记忆：`exe` → Widget（或 Gateway）/ Host / Core；Host 持组合根与文档；业务经契约接口访问，避免 Widget 直穿 Data 内部。

更细依赖图：[MODULE_DEVELOPER_GUIDES.md](../MODULE_DEVELOPER_GUIDES.md)。
