# 01 — 仓库与文档总览

## 文档优先级

1. 源码旁 **`DEVELOPER_GUIDE.md`**
2. 本手册、`docs/features/`、本目录约定（布局 / 格式 / 空间契约）
3. 仓库外归档 zip（路径见 [ARCHIVE_ZIP_LOCATION.txt](../ARCHIVE_ZIP_LOCATION.txt)）

## 仓库地图

```text
CloudSim/                 # git 仓库根（本产品）
├── docs/                 # ★ 开发文档入口
│   ├── README.md
│   ├── solutions/
│   ├── features/
│   ├── 开发手册/
│   ├── DIRECTORY_LAYOUT.md / SOURCE_CONVENTIONS.md / spatial_contract_*.md
│   └── MODULE_DEVELOPER_GUIDES.md
├── CloudSim.sln / CloudSimWeb.sln
├── src/
├── web/cloudsim-web-ui/
└── scripts/
# 仓库旁（工作区）
../Setup/packaging/       # 安装包
../bin/                   # Debug→x64d，Release→x64
```

## 产物目录

| 配置 | 二进制 | 网页静态 |
|------|--------|----------|
| Debug\|x64 | `bin\x64d\` | `bin\x64d\web\` |
| Release\|x64 | `bin\x64\` | `bin\x64\web\` |

以各工程 `OutDir` / `Directory.Build.props` 为准，勿擅自改路径或只拷到 `CloudSim\bin\`。
