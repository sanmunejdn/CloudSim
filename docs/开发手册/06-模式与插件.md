# 06 — 模式与插件

顶栏工作区：主程序（内建）→ 几何建模 → 工艺流程 → 工程图。契约见 [后端对象与软件模式](../features/后端对象与软件模式/README.md)。

## 工作区模式

| 模式 | modeId | 专题 | 工程指南 |
|------|--------|------|----------|
| 主程序 | `""` | [主程序](../features/主程序/README.md) | Widget / Host / RobotWidget / Data |
| 几何建模 | `com.cloudsim.geomodeling` | [几何建模](../features/几何建模/) | [GeometricModelingPlugin](../../src/Plugins/GeometricModelingPlugin/DEVELOPER_GUIDE.md) |
| 工艺流程 | `com.cloudsim.processflow` | [工艺流程](../features/工艺流程/) | [ProcessFlowPlugin](../../src/Plugins/ProcessFlowPlugin/DEVELOPER_GUIDE.md) |
| 工程图 | `com.cloudsim.drawing` | [工程图](../features/工程图/) | [EngineeringDrawingPlugin](../../src/Plugins/EngineeringDrawingPlugin/DEVELOPER_GUIDE.md) |

进入模式：插件 `claimWorkspaceMode`；返回主程序：宿主 `returnToMainWorkspace`（空 `modeId`）。

几何建模桌面 ↔ 网页能力对照：[CloudSim/README.md](../../README.md)「几何建模：桌面逻辑 → 网页」· [FEATURES.md](../features/几何建模/FEATURES.md)。

## 插件类型

完整表：[features/插件](../features/插件/README.md) · [src/Plugins/README.md](../../src/Plugins/README.md)

| 类型 | 成员（摘要） |
|------|----------------|
| 工作区模式 | GeometricModeling / ProcessFlow / EngineeringDrawing |
| 侧栏工具 | Geometry / PointCloud / PlcComm / IndustrialCamera / Labeling / PointNet |
| AI | CloudSimAiSDK、AiWidget、PointNet |
| 轨迹 / 通讯 SDK | CloudSimMeshTrajectorySDK、RobotCommSDK |
| 契约 SDK | CloudSimPluginSDK |

宿主扫描与上下文：[CloudSimPluginHost](../../src/UI/CloudSimPluginHost/DEVELOPER_GUIDE.md)（源码编入 `CloudSimHost.dll`）。

产物目录：`bin\x64(d)\plugins\<pluginId>\`（以各插件 vcxproj 为准）。
