# 04 — 世界坐标与后端对象

## 权威契约

**必读**：[spatial_contract_world_pose.md](../spatial_contract_world_pose.md)（v2）

| 要点 | 约定 |
|------|------|
| 权威存储 | `BackendMat4 worldMatrix`（16 元列主序）；JSON 只持久化它 |
| 几何 | `geometry` = 出生坐标；用户移动只改 `worldMatrix` |
| 变换 | `p_world = p_geometry × worldMatrix`（OSG 行向量语义） |
| 属性面板 | `pose` / `rotation` 是分解视图，不是独立存储 |
| URDF 连杆 | geometry 在 link 文件系；`worldMatrix` 由 FK 每帧刷新 |
| 已废弃 | 独立 `pose`/`rotation` JSON、手写 `T×R` 拼装 |
