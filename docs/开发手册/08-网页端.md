## 运行与构建

| 项 | 说明 |
|----|------|
| 默认访问 | `http://127.0.0.1:8787`（`--port=` 可改） |
| 静态资源 | `{exe}/web`（即 `bin\x64(d)\web`） |
| 前端有 Node | 在 `web/cloudsim-web-ui`：`npm run build:debug` / `build:release` |
| 无 Node 兜底 | `CLOUDSIM_WEB_FALLBACK=1`；**正式安装包不要用 fallback** |

共享后端与桌面同源（Data / 轨迹等）；桌面 Qt 插件壳与互斥工作区不进网页 UI。工程侧车 `processFlow` / `geometricModeling` 仍可经 `/api/sidecar/*` 读写保真。

改 Host 共享源后：

```bash
python scripts/check_host_headless_sources.py
```

并 Debug|x64 + Release|x64 编译 `CloudSimHostHeadless`。
