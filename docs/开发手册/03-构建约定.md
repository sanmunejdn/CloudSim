# 03 — 构建与源码约定

## 编译验证

修改需编译验证的 C++/插件时，**必须**同时构建：

```text
msbuild <path>.vcxproj /p:Configuration=Debug /p:Platform=x64
msbuild <path>.vcxproj /p:Configuration=Release /p:Platform=x64
```

| 禁止 | 说明 |
|------|------|
| 只编 Debug | 不得声称「编译通过」 |
| 改 OutDir / 私拷 DLL | 以 vcxproj / `Directory.Build.props` 为准 |
| 用错运行目录 | Debug 对 `bin\x64d`，Release 对 `bin\x64` |

依赖链按顺序编（例：GeometryAlgorithm → Data → CloudSimHost → 相关插件），Debug 与 Release 各一遍。改 Host 共享源时另编 `CloudSimHostHeadless`，并跑：

```bash
python scripts/check_host_headless_sources.py
```

## 源码格式

权威全文：[SOURCE_CONVENTIONS.md](../SOURCE_CONVENTIONS.md)

| 项 | 约定 |
|----|------|
| 编码 | UTF-8 **with BOM** |
| 换行 | CRLF |
| Include 守卫 | `#ifndef 工程_文件_H`，禁止 `#pragma once` |
| 格式化 | 仓库根 `.clang-format`（Tab / Allman / 列宽 120） |
| 筛选器 | 新增源后 `generate_vcxproj_filters.py --sync` |

在 `CloudSim/` 根推荐顺序：

```bash
python scripts/fix_chinese_mojibake.py   # 按需
python scripts/normalize_header_guards.py  # 按需
python scripts/ensure_file_headers.py      # 按需
python scripts/run_clang_format.py
python scripts/normalize_source_encoding.py   # 须在 format 之后
python scripts/generate_vcxproj_filters.py --sync
```

Host 接口与 backend 调用清单：[Host优化](../features/Host优化/)。
