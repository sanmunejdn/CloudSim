# ACCEPTANCE 更新：日志遮挡二次修复

## 根因（相对上次）

1. **通栏 Bottom Dock + 侧栏未收缩**：`setCorner(...BottomDockWidgetArea)` 让日志横跨右侧列，但 `hideDockTitleBar` 下侧栏高度未可靠缩短 → 日志「清空」压在轨迹/AI 底栏上。
2. **AI 助手内部**：`QTextBrowser` `minHeight=160` + 拉伸，父面板高度不足时从底部裁切 → 输入框/设置被挤没（截图里只剩历史区，底部「清空」实为日志顶栏）。

## 本次修复

| 项 | 做法 |
|----|------|
| 日志位置 | 迁入中央竖向 `QSplitter`，去掉 `m_runDock` |
| 侧栏 | 通高（底角归 Left/Right Dock） |
| AI 底栏 | 输入条 `Fixed` 高度；历史 `minHeight=48`，优先压缩历史 |
| 右侧默认宽 | 240 → 360 |

## 验收

- [ ] 轨迹生成/编辑底栏控件完整可见，右侧不再出现日志「清空」压盖
- [ ] AI 助手可见：输入框 + 设置 + 发送
- [ ] 日志仍在中央 3D 下方，可拖分割条调节高度（≤220）
