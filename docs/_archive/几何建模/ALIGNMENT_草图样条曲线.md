# ALIGNMENT — 草图样条曲线

## 原始需求

草图绘制增加样条曲线。

## 项目理解

- 草图实体现为：点 + 直线 / 三点圆弧 / 圆；JSON 存于 `sketchDocumentUtf8`。
- 工具：`SketchToolKind` + `ISketchTool`；Ribbon 按钮切工具；右键在多数绘制工具中为取消。
- Overlay / Pad / Sweep 导出均基于折线采样（圆弧已采样）；无原生样条路径段。
- PlaneGCS 含 BSpline 但未接入；OneCAD 仅有 `Spline // Future` 占位。

## 建议 MVP（待确认）

1. **插值样条**：左键依次点过点，右键结束提交（≥2 点；推荐 ≥3 点更平滑）。
2. **算法**：过点 Catmull-Rom → 三次段，本地采样；不接入约束求解器。
3. **导出**：采样为折线，参与封闭轮廓 / 开放路径（与圆弧采样同类）。
4. **Ribbon**：新增「样条」按钮。
5. **本期内不做**：约束/尺寸贴合样条、Trim/Mirror 样条、GCS BSpline、控制点编辑手柄。

## 边界确认

| 纳入 | 不纳入（本期） |
|------|----------------|
| 绘制、显示、删除、JSON 持久化 | 样条约束 / PlaneGCS |
| Overlay 采样显示 | 控制多边形拖拽编辑 |
| Pad/Pocket/Sweep 折线导出 | 修剪、镜像样条 |

## 疑问澄清（按优先级）

1. **结束手势**：右键结束提交 vs 双击结束？（SDK 无双击事件，双击需工具内计时模拟）
2. **最少点数**：2 点（退化为折线/直线）还是至少 3 点？
3. **是否纳入封闭轮廓/扫描路径导出**，还是仅显示？
4. **首期是否需要构造线切换**（与直线一致）？
