# CONSENSUS — SW 差距续期（推荐方案，待你确认后开干）

## 需求描述

在现有 Part MVP（含圆角/旋转/阵列/镜像/放样/抽壳/多环孔/投影边）之上，再推一期「草图标配 + 扫描硬化 + 参考几何入门」，显著提升日常建模流畅度；装配与曲面仍不做。

## 推荐下一里程碑：「草图标配 + 扫描硬化」

| 序 | 功能 | 对应原清单 | 交付形态 | 验收要点 |
|----|------|------------|----------|----------|
| 1 | **椭圆 / 正多边形 / 直槽口** | P1 草图标配 | 绘制工具 + 离散导出进轮廓 | Ribbon 可画；Pad 能出体 |
| 2 | **等距 Offset** | P1 | 选闭合环 → 内外偏置 → 新环/替换 | 单环 MVP；失败有提示 |
| 3 | **转换实体 Convert** | P1（投影边增强） | 点选面/边 → 投影为草图边（可构造） | 与现「投影边」合并体验 |
| 4 | **扫描增强 MVP** | P2 | 模型边作路径；视口点选路径边；可选扭转角 | 侧栏参数；预览失败可读 |
| 5 | **拉伸：到顶点 / 到面偏移** | P2 终止家族 | `ExtrudeEnd` 扩枚举 + rebuild | 侧栏可选；rebuild 可复现 |
| 6 | **独立拔模 Draft** | P2 | 新 kind + 选面 + 中性面/方向 + 角度 | 特征树可删回退 |

**刻意后置（本里程碑不做）**

- 引导线扫描、薄壁扫描（算法面大）
- Rib / 孔向导
- 完整基准体系（仅可做「用户基准面」单点试点，见备选包）
- 持久拓扑命名引擎、PM 面板大改、特征级 Suppress

## 备选加包（二选一，确认后并入或顺延）

**A. 参考几何入门**：用户基准面（三点/等距/成角）写入特征树（非虚拟原点）  
**B. 阵列升级**：LinearPattern 改为「选上游特征 id + tip 布尔」，更接近 SW 特征阵列

- 新 Host API 须 bump `CLOUDSIM_PLUGIN_HOST_VERSION`
- 注释纯中文、少而聚焦 Why；改动保持外科手术式

## 建议落地顺序（实现时）

```text
椭圆/多边形/槽口 → Offset → Convert 合并投影边
    → 扫描模型边路径 + 扭转角
    → UpToVertex / OffsetFromFace
    → Draft
```

## 验收总标准

1. Debug|x64：GeometryAlgorithm / Data / CloudSimHost / GeometricModelingPlugin 编译通过  
2. 每项有 Ribbon 或侧栏入口，特征树可见（生成特征）  
3. 历史 JSON 往返后 rebuild 形状可恢复（弱引用失败时有明确错误，不静默坏体）
