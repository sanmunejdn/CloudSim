# ALIGNMENT：坐标系后端对象

## 原始需求

在菜单栏添加「坐标系」入口：可定义名称与位姿，生成后端对象；外部 TCP（转换工件型）可通过下拉框选择该坐标系。

## 已确认决策

1. **后端类型**：新建 `FrameBackendData`（独立注册/可视化/IO）
2. **外部 TCP**：下拉选坐标系；选中后自动用位姿并隐藏六参数；「手动」兼容旧参数
3. **菜单位置**：独立「插入」菜单（View 与 Settings 之间）

## 边界

**在范围内**：菜单创建、Frame 后端、轴可视化、工程存盘、ToWorkpiece 下拉与运行时解析  
**不在范围内**：与机器人 Tool/User 帧互通、装配 Follow、从 TCP 捕获创建
