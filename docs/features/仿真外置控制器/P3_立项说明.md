# P3 立项说明 — 笛卡尔 IK / 多会话 / 生态

> 本波交付：**协议草案 + 错误码预留**；Host 对 `STEP_POSE` 返回明确 ERROR，待产品确认后接 `RobotTeachIk`。

## STEP_POSE（建议 protocolVer=2）

```json
{
  "type": "STEP_POSE",
  "protocolVer": 2,
  "dtMs": 16,
  "targetTcpMm": [x, y, z],
  "targetEulerDeg": [rx, ry, rz],
  "frame": "robot_base"
}
```

Host：调用现有 TeachIk → `applyJointAngles` → `STEP_REPLY`；失败 `ERROR.code=IK_FAILED`。

## 多会话

按 `robotInstanceIndex` 多 TCP 端口或单端口多路复用（需另立设计）。MVP 仍单连接。

## ROS / IPC / SimReal 门面

独立进程桥；端口不得占用 19610/19620 语义混用。

## 本仓库当前行为

`ControllerManager` 识别 `STEP_POSE` 时回：

```json
{ "type":"ERROR", "protocolVer":1, "code":"NOT_READY", "message":"STEP_POSE reserved for protocolVer=2 (see P3 design)" }
```
