# P4 设备语义增量 — Webots 借鉴落地

> protocolVer 仍为 **1**（向后兼容加字段/错误码）。v2 留给 `STEP_POSE`。

## 增量摘要

| 项 | 行为 |
|----|------|
| HELLO_ACK 限幅 | `jointLowerRad` / `jointUpperRad`（长度 = jointCount） |
| STEP 越界 | `ERROR.code=OUT_OF_LIMITS`，不入 pending、不静默 clamp |
| STEP dt | `dtMs` 须为正且为 `simDtMs`(16) 正整数倍，否则 `BAD_DT` |
| STEP_REPLY sensors | `sensors.jointPosition` 与 `actualJointRad` 同源；后续传感只加键 |
| 环境变量 | `CLOUDSIM_HOST=127.0.0.1:19620`、`CLOUDSIM_ROBOT_INDEX=0` |
| 对话框 | 控制器 stdout/stderr 汇入日志区（MergedChannels） |

## HELLO_ACK（增量字段）

```json
{
  "type": "HELLO_ACK",
  "protocolVer": 1,
  "simDtMs": 16,
  "jointCount": 6,
  "jointNames": ["j0"],
  "jointLowerRad": [-3.14],
  "jointUpperRad": [3.14]
}
```

文档无限幅时 Host 用 `±π` 兜底并 `qWarning`。

## STEP_REPLY（增量字段）

```json
{
  "type": "STEP_REPLY",
  "protocolVer": 1,
  "simTimeMs": 160,
  "actualJointRad": [0.0],
  "sensors": { "jointPosition": [0.0] }
}
```

## 新增错误码

| code | 含义 |
|------|------|
| OUT_OF_LIMITS | `targetJointRad` 任一轴越界 |
| BAD_DT | `dtMs<=0` 或非整倍 `simDtMs` |

## 验收

1. HELLO_ACK 含限幅数组  
2. 越界 STEP → `OUT_OF_LIMITS`  
3. `dtMs=17` → `BAD_DT`  
4. 正常 STEP → `sensors.jointPosition`  
5. 对话框 Run → 日志可见 print；Python/C++ 读 `CLOUDSIM_HOST`
