# P6 — 多机多会话

## 端口

`port = 19620 + robotInstanceIndex`（实例 0 → 19620）。

每端口一个 `ControllerManager`；`HELLO.robotInstanceIndex` 必须与端口绑定实例一致，否则 `BAD_ROBOT_INDEX`。

## 桌面

外置勾选后对文档内全部实例 listen；对话框可选实例，Run 注入：

- `CLOUDSIM_HOST=127.0.0.1:<port>`
- `CLOUDSIM_ROBOT_INDEX=<i>`

## Headless / Gateway

`POST /api/robot/external-controller/start`

- 默认 `allInstances`：全部实例开端口
- 或 body：`{"robotInstanceIndex":0,"allInstances":false}` 只开一台

## 验收

单机行为不变；两台机器人两端口各跑 sine，互不抢轴。
