# P0 语义附录 — 外置控制器

## 无 STEP 时

`ControllerManager::tickApply` 在无 pending STEP 时直接返回：关节**保持末姿态空转**，不推进 `simTimeMs`。

## 断连

`closeClient` 仅关闭 socket；不复位关节。Host 继续 listen。

## actualJointRad

`applyPendingToScene` 后经 `IRobotSimulationDocument::robotLocalJointAnglesForInstance` 采样文档真源；失败时回退为已应用目标（与 `noteRobotJointAnglesApplied` 一致）。

## dtMs

仍「来帧即应用」。若 `dtMs` 不是 `simDtMs`(16) 的正整数倍，Host 打 `qWarning`，不拒绝帧。
